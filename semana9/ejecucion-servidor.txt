- ¿Qué ocurre cuando ejecutas `node server.js`?
 El proceso inicia la aplicación de Node.js y levanta el servidor web local.
- ¿Qué mensaje aparece en la terminal? 
Debería mostrarse el mensaje programado en el `console.log`: "Servidor ejecutándose en puerto 3000".
- ¿Qué sucede cuando visitas la ruta `/estado`? 
El navegador o cliente recibe una respuesta en formato JSON con el estado actual:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
